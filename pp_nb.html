「Safe QRScan」 プライバシーポリシー


    Motoki Takahashi（以下、「当方」といいます。）は、スマートフォン用アプリケーション「Safe QR」（以下、「本アプリケーション」といいます。）に関するサービスの円滑な提供を実施させていただくために、プライバシーポリシーを定め、利用者情報の保護に努めます。

    1.利用者情報の取得と利用目的

Acquisition Method
Information Name
Purpose of Use

QR code reading by the user
URL of the QR code
URL access by the user

Data input for QR by the user
Data for QR
Generate and save QR images 

    2.利用者情報の取得
    本アプリケーションでは情報収集モジュールを使用しておりません。

    3.利用者情報の第三者提供
    本アプリケーションでは情報を開発者のサーバーに送信しないため、当方が情報を第三者に開示または提供することはありません。


    4.プライバシーポリシーの公開
    プライバシーポリシーは本アプリケーションの「ユーザー編集画面」の「プライバシーポリシー画面」および、URL(https://)に公開されます。


    5.プライバシーポリシーの変更
    当方は、法令の変更等に伴い、本プライバシーポリシーを変更することがあります。

    制定: 2023年12月05日
    改訂: 2026年04月29日
